## How to read the four states

These are distinct and the difference matters commercially.

| State | Meaning | Action |
|---|---|---|
| **Missing** | On your request list, not supplied | Request it |
| **Not found** | Referenced by a supplied document, never requested because you did not know it existed | Request it |
| **Unreviewed** | Supplied, but could not be opened | Ask for access, **not** for the document |
| **Not applicable** | Confirmed not relevant | No action |

Asking the seller to re-send a document they already sent costs credibility. One item
below is unreviewed, not missing.
